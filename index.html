Implementación método Splines 3D

Por: Sergio Andrés Guevara y William Sebastián Cabrera

Con esta implmentación buscamos simular y reconstruir la trayectoria de un vuelo comercial en 3D a partir de datos de tipo GPS, incorporando fenómenos reales, tomando en cuenta variables como la velocidad variable en el tiempo, la altitud con comportamiento suave y una trayectoria horizontal curva.

Esto lo realizaremos por medio de interpolación polinomial, más específicamente con el método de splines 3D. Esto se debe a que el uso de splines cúbicos paramétricos en 3D es adecuado para la reconstrucción de trayectorias de vuelo, ya que garantizan continuidad hasta la segunda derivada, lo cual es consistente con las leyes físicas del movimiento. Además, estos splines minimizan funcionales de energía asociados a la curvatura, produciendo trayectorias suaves y estables. Su formulación local evita oscilaciones numéricas y permite trabajar con particiones temporales no uniformes, lo que los hace especialmente apropiados para modelar sistemas dinámicos con velocidad variable y datos ruidosos.

Sabemos que los splines cúbicos usualmente tienen la siguiente forma:

$$s_i(x)=a_i + b_i(x-x_i) + c_i(x-x_i)^2 + d_i(x-x_i)^3$$

Podemos notar que, para $n$ puntos de datos y con $i=0,1,2,\dots,n-1$, existen $n-1$ intervalos y, con esto, $4(n-1)$ constantes que desconocemos, las cuales están asociadas a los coeficientes del polinomio, es decir, $(a,b,c,d)$. Por ende, necesitamos $4(n-1)$ ecuaciones que nos permitan encontrar estas constantes.

Las ecuaciones que usaremos son las siguientes:

  1. $s(x)$ es un polinomio cúbico, el cual se denota como $s_j(x)$ en el intervalo $[x_j,x_{j+1}]$ para $j=0,1,2,\dots,n-1$.
  2. $S_j(x_j)= f(x_j)$ y $S_j(x_{j+1})=f(x_{j+1})$ para $j=0,1,2,\dots,n-1$.
  3. $S_{j+1}(x_{j+1})=S_j(x_{j+1})$ para $j=0,1,2,\dots,n-2$.
  4. $S'_{j+1}(x_{j+1})=S'_j(x_{j+1})$ para $j=0,1,2,\dots,n-2$.
  5. $S''_{j+1}(x_{j+1})=S''_j(x_{j+1})$ para $j=0,1,2,\dots,n-2$.
  6. Se cumple una de las siguientes condiciones de frontera: $S''(x_0)=S''(x_n)=0$ o $S'(x_0)=f'(x_0)$, $S'(x_n)=f'(x_n)$.

Para aplicar splines cúbicos en 3D usaremos este mismo método; sin embargo, buscaremos generar una curva paramétrica:

$$r(t)=(x(t),y(t),z(t))$$

donde cada una de las componentes es un spline cúbico que satisface de forma independiente las condiciones anteriormente mencionadas, y realizamos la interpolación de los puntos $(x,y,z)\in \mathbb{R}^3$.
